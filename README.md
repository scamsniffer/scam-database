# ScamSniffer — Crypto Phishing Domain & Scam Address Blocklist

Open blocklists of crypto phishing domains and scam addresses, maintained by [ScamSniffer](https://www.scamsniffer.io/?utm_source=git-repo). The lists cover wallet drainer sites, fake airdrop and token-claim pages, and sites impersonating projects such as OpenSea, MetaMask and Uniswap.

- **358k+ phishing domains**, **2.5k+ scam addresses** (as of Oct 2026)
- Updated daily (~05:00 UTC)
- Published with a **7-day delay** — real-time data is available via the [Blocklist API](#real-time-blocklist-api)

## Phishing Domain & Scam Address Lists

| File | Format | Contents |
|---|---|---|
| [`blacklist/domains.json`](blacklist/domains.json) | `string[]` | Phishing hostnames, e.g. `"claim-paws.community"` |
| [`blacklist/address.json`](blacklist/address.json) | `string[]` | Scam addresses, EVM only (Ethereum and EVM chains), lowercase hex |
| [`blacklist/combined.json`](blacklist/combined.json) | `{ [domain]: string[] }` | Phishing domain → addresses observed on that site |
| [`blacklist/all.json`](blacklist/all.json) | `{ domains, address, combined }` | The three files above in one object |
| [`blacklist/archive/`](blacklist/archive) | `{ domains: string[] }` per file | Domains added on each day, one file per day (`YYYY-MM-DD.json`), since 2022-05-31 |

## How to Check a URL or Address

Raw URLs:

```
https://raw.githubusercontent.com/scamsniffer/scam-database/main/blacklist/domains.json
https://raw.githubusercontent.com/scamsniffer/scam-database/main/blacklist/address.json
```

Check a domain from the shell:

```bash
curl -s https://raw.githubusercontent.com/scamsniffer/scam-database/main/blacklist/domains.json \
  | jq -e --arg d "example.com" 'any(.[]; . == $d)'
```

Check a URL or address in JavaScript:

```js
const BASE = "https://raw.githubusercontent.com/scamsniffer/scam-database/main/blacklist";
const domains = new Set(await (await fetch(`${BASE}/domains.json`)).json());
const addresses = new Set(await (await fetch(`${BASE}/address.json`)).json());

// Match the hostname and each parent domain: a.b.example.com, b.example.com, example.com
function isPhishingUrl(url) {
  const parts = new URL(url).hostname.toLowerCase().split(".");
  for (let i = 0; i < parts.length - 1; i++) {
    if (domains.has(parts.slice(i).join("."))) return true;
  }
  return false;
}

const isScamAddress = (addr) => addresses.has(addr.toLowerCase());
```

Cache the lists locally and refresh at most once a day — they only change once a day.

## Report a Phishing Site or Address

[Open an issue](https://github.com/scamsniffer/scam-database/issues/new) with:

- the domain or address (and chain)
- evidence: a screenshot, the drain transaction hash, or the wallet request the site makes

The JSON files are generated by our pipeline, so pull requests that edit them are overwritten. Please use issues instead.

## False Positives

If your site or address is listed by mistake, [open an issue](https://github.com/scamsniffer/scam-database/issues/new?title=%5BLegitimate+Site+Blocked%5D+) titled `[Legitimate Site Blocked] <domain>` and include:

- the exact domain or address (check it is in the list — look-alike domains such as `reward-<yourname>.org` are separate entries)
- who operates it and how to verify that (official site, X account, docs)
- when you acquired the domain, if it was previously used by someone else

## FAQ

**How do I check if a website is a crypto phishing site?**
Look up its hostname in [`domains.json`](blacklist/domains.json) (see [How to Check a URL or Address](#how-to-check-a-url-or-address)), or install the [ScamSniffer Chrome extension](https://chromewebstore.google.com/detail/scam-sniffer/mnkbccinkbalkmmnmbcicdobcmgggmfc), which warns before you connect a wallet or sign on a phishing site.

**Is this list free to use?**
Yes, under [GPL-3.0](LICENSE). The public lists are published with a 7-day delay; real-time data is available via the [Blocklist API](#real-time-blocklist-api).

**Which chains do the scam addresses cover?**
Ethereum and other EVM chains.

**My site was flagged as phishing. How do I get it removed?**
See [False Positives](#false-positives).
