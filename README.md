# ScamSniffer — Crypto Phishing Domain Blocklist

An open blocklist of crypto phishing domains, maintained by [ScamSniffer](https://www.scamsniffer.io/?utm_source=git-repo). It covers wallet drainer sites, fake airdrop and token-claim pages, and sites impersonating projects such as OpenSea, MetaMask and Uniswap.

- **358k+ phishing domains** (as of Oct 2026)
- Updated daily (~05:00 UTC)
- Published with a **7-day delay** — real-time data is available via the [Blocklist API](#real-time-blocklist-api)

## Phishing Domain List

| File | Format | Contents |
|---|---|---|
| [`blacklist/domains.json`](blacklist/domains.json) | `string[]` | Phishing hostnames, e.g. `"claim-paws.community"` |
| [`blacklist/archive/`](blacklist/archive) | `{ domains: string[] }` per file | Domains added on each day, one file per day (`YYYY-MM-DD.json`), since 2022-05-31 |

> `address.json`, `combined.json` and the `address` / `combined` keys in `all.json` are no longer updated (last update: February 2024). They are kept so existing integrations do not break.

## How to Check a URL

Raw URL:

```
https://raw.githubusercontent.com/scamsniffer/scam-database/main/blacklist/domains.json
```

Check a domain from the shell:

```bash
curl -s https://raw.githubusercontent.com/scamsniffer/scam-database/main/blacklist/domains.json \
  | jq -e --arg d "example.com" 'any(.[]; . == $d)'
```

Check a URL in JavaScript:

```js
const URL_LIST = "https://raw.githubusercontent.com/scamsniffer/scam-database/main/blacklist/domains.json";
const domains = new Set(await (await fetch(URL_LIST)).json());

// Match the hostname and each parent domain: a.b.example.com, b.example.com, example.com
function isPhishingUrl(url) {
  const parts = new URL(url).hostname.toLowerCase().split(".");
  for (let i = 0; i < parts.length - 1; i++) {
    if (domains.has(parts.slice(i).join("."))) return true;
  }
  return false;
}
```

Cache the list locally and refresh at most once a day — it only changes once a day.

## Report a Phishing Site

[Open an issue](https://github.com/scamsniffer/scam-database/issues/new) with:

- the domain, and any scam addresses it uses (with chain)
- evidence: a screenshot, the drain transaction hash, or the wallet request the site makes

The JSON files are generated by our pipeline, so pull requests that edit them are overwritten. Please use issues instead.

## False Positives

If your site is listed by mistake, [open an issue](https://github.com/scamsniffer/scam-database/issues/new?title=%5BLegitimate+Site+Blocked%5D+) titled `[Legitimate Site Blocked] <domain>` and include:

- the exact domain (check it is in the list — look-alike domains such as `reward-<yourname>.org` are separate entries)
- who operates it and how to verify that (official site, X account, docs)
- when you acquired the domain, if it was previously used by someone else

## FAQ

**How do I check if a website is a crypto phishing site?**
Look up its hostname in [`domains.json`](blacklist/domains.json) (see [How to Check a URL](#how-to-check-a-url)), or install the [ScamSniffer Chrome extension](https://chromewebstore.google.com/detail/scam-sniffer/mnkbccinkbalkmmnmbcicdobcmgggmfc), which warns before you connect a wallet or sign on a phishing site.

**Is this list free to use?**
Yes, under [GPL-3.0](LICENSE). The public list is published with a 7-day delay; real-time data is available via the [Blocklist API](#real-time-blocklist-api).

**My site was flagged as phishing. How do I get it removed?**
See [False Positives](#false-positives).
